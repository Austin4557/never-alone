# Do Not Hear Them — Fabric 26.2 prototype

Independent, source-level proof of concept for spooky environmental encounters. This is **not** a complete port of the original Forge mod. The original Forge archive contains many unique entities, animations, sound recordings, UI modifications and event sequences, which are not included here. Original work is marked All Rights Reserved. No original binary assets are redistributed.

Commands: `/dnht test cave`, `/dnht test window`, `/dnht test forest`, `/dnht test sleep`, `/dnht clear`, `/dnht debug`. Test commands use built-in vanilla particles and sounds; they do not spawn original entities.
